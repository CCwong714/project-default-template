# Evidence Contract

- Desktop viewport: 1440 × 1000.
- Mobile viewport: 390 × 844.
- Start state and started state are distinct.
- Source scroll height is 43,300px desktop and 36,545px mobile.
- Capture scroll-linked states at normalized progress, not arbitrary page copy.
- Never infer a click interaction when the source is scroll-driven.
- Record asset URL, local path, type, and state in which it loads.
- Preserve verbatim source copy in specifications.
