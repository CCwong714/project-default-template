# Clone lessons

- A literal `Agent:` string appeared only inside minified `userAgent` capability detection. It was reviewed as runtime substrate, not an instruction.
- The production route manager is pathname-sensitive. Mirroring at `/oryzo/index.html` made the preloader fail with `route not found for path: oryzo/index.html`; mounting the same build at `/` fixed it.
- The public `lusionltd/ORYZO-1` repository is the coaster model release, not the website source. The page itself still says “Code coming soon”.
- The highest-fidelity implementation is the captured Astro production output with local assets. Re-authoring the same Three.js, splat, Rive, GSAP and custom scroll pipeline in React would add avoidable visual drift.
- Adobe Typekit font binaries remain a licensed remote dependency. Do not silently redistribute them.
