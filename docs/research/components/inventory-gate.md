# InventoryGate 组件规格

- 场景总高 `300vh`，向上覆盖前一段 `100vh`；内部是 `100vh` sticky
  舞台，`padding-block: 5vw`，内容垂直居中。
- 上方背包行占满场景宽度。背包 Lottie 宽 `90%`、最小 `150px`、
  最大 `350px`。
- 装饰必须使用原站素材而不是 CSS 多边形：
  `5ea2da8fc0c91ee7e2c558d5_cercle-triangle.svg` 为
  `250–350px`，`5eb5261abde4bb61c8ab7868_rond-hachure-bleu.png`
  为 `90–200px`、透明度 `.65`。
- 装饰跟随场景滚动，不做无限旋转。场景进度 `.34 → 1` 时白色圆从
  `scale(1.5) rotate(0deg)` 变为 `scale(1) rotate(-70deg)`；
  `.34 → .50` 时透明度 `0 → .29`。蓝色斜线圆同时
  `rotate(0deg) → rotate(70deg)`。
- 桌面：三张 `200×260px` 物品卡横排，水平边距 `18px`，卡片区域
  左右各保留 `5vw`。
- 手机：三张卡改为 100px 高横向行，物品内容在左、动作区在右。
- 当前物品按钮为蓝色可点击，未来物品为白框禁用，完成物品为绿色 OK。
- 卡片标题默认下移约 `20–30px` 且透明；hover 时标题在 `300ms`
  内进入，同时物品图标放大至 `1.3` 并旋转 `9deg`，离开时反向恢复。
- 点击每件物品后重新播放一次背包动画，整轮 `4s`。按钮完成态淡入
  `500ms`，下一按钮显示/淡入 `300ms`。
- 完成第三件后在背包中央用 `1s` 淡入绿色 check，并显示
  `40×40px` 的原站 Lottie 箭头；箭头链接到 `#go`。
